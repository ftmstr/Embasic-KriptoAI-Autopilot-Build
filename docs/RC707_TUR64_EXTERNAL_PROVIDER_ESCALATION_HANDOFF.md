## What was actually learned about third-party capabilities

**GitHub:** The [official job logs REST endpoint](https://docs.github.com/en/rest/actions/workflow-jobs) issues a redirect to a *plain-text* log download; [artifact attestations](https://docs.github.com/en/actions/how-tos/secure-your-work/use-artifact-attestations) bind an artifact subject/digest, **not** an automatic signature over the original job-log byte stream. The real unchanged workflows have only `contents: read`, no `id-token: write` or `attestations: write`. A documented provider-signed original RAW log receipt was **not obtained**, and no GitHub Support ticket has been submitted by this development turn. The official [GitHub Support portal](https://docs.github.com/en/support/contacting-github-support/creating-a-support-ticket) and [Actions support guidance](https://docs.github.com/en/actions/how-tos/get-support) provide the formal contact route. **Do not downgrade the requirement even if the provider cannot supply it.**

**Rekor:** [Rekor Tiles clients](https://github.com/sigstore/rekor-tiles/blob/main/CLIENTS.md) describe historical checkpoints and initial v2 witness limits. [Rekor specification](https://github.com/sigstore/architecture-docs/blob/main/rekor-spec.md) requires verifier-held historical checkpoints and consistency; no separately OOB-pinned project log/witness authorization, authentic C2SP historical checkpoint or RFC6962 consistency has been acquired. The initial launch's witness state must not be projected onto current service status. RC703 mathematical Ed25519 experiments are **not** audited production cryptography.

**AWS:** [DynamoDB MRSC design](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/bp-global-table-design.html) requires exactly three regions and supports strong reads/conditional writes; [PITR recovery](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/pointintimerecovery_restores.html) restores to a **new** table. No independently administered real MRSC service, multiple physical hosts performing concurrent CAS, restore anti-reenrollment verification, or independently authenticated external recipient ACK was obtained. AWS replication witness != independently pinned Rekor witness.
