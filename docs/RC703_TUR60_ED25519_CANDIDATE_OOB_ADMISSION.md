## 2. Independent source research and real technical limits

**RFC 8032 Ed25519**, especially section 7.1 official public test vectors and section 5.1.7 signature verification: https://www.rfc-editor.org/rfc/rfc8032 . **C2SP Signed Notes**: https://c2sp.org/signed-note@v1.0.0-rc.1 . **C2SP timestamped witness cosignatures**: https://c2sp.org/tlog-cosignature@v1.0.1 . A C2SP log signs the original note body (including final newline), while a witness signs `cosignature/v1\ntime <decimal>\n` followed by the same note body. Valid signed-message equations prove only that *some private key corresponding to the public key passed to the verifier* signed the bytes. A candidate public key, candidate key-ID, or user-supplied status flag does **NOT** establish OOB pinning, custody, owner/reviewer authority, legal/administrative independence, trusted time, key revocation, or historic log-root provenance.

**Sigstore Rekor Tiles**: current client documentation https://github.com/sigstore/rekor-tiles/blob/main/CLIENTS.md describes offline verification of inclusion/checkpoints, and notes that its initial Rekor v2 launch did not have witnessed checkpoints while awaiting a public witness network. Do **not** assume a live independent witness is currently available without a specific verified checkpoint. The maintained Go `verify` package exposes witnessed checkpoint and consistency proof functions: https://pkg.go.dev/github.com/sigstore/rekor-tiles/v2/pkg/verify . The public library exists but independent user-approved trust roots / real historical proof bundle are **not connected to this session**.

**AWS MRSC candidate, not real CAS evidence:** https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/V2globaltables_HowItWorks.html . MRSC supports strongly consistent three-Region single-item conditional writes; MREC uses last-writer-wins and cannot be used as observed cross-region durable anti-rollback CAS. An AWS replication witness is *not* a different-admin Rekor cryptographic witness.
